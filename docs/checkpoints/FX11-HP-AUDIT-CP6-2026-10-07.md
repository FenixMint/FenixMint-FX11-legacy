## Proposed apply strategy

Do not disable everything in one opaque action.

Preferred reversible sequence:

1. capture current feature state;
2. disable Virtual Machine Platform;
3. verify feature state;
4. disable Hyper-V;
5. reboot when required;
6. verify:
   - HypervisorPresent
   - VBS runtime state
   - power capabilities
   - Secure Boot / TPM state unchanged
   - networking/storage/device health
7. if regression occurs, re-enable the affected feature.

## Architecture lesson

A feature can move through FX11 classification as evidence accumulates:

```
UNKNOWN
-> REVIEW
-> CONDITIONAL
-> OPTIONAL-CANDIDATE
-> SAFE-CANDIDATE
-> APPLY only after owner approval
```

This is the intended FX11 decision model.
